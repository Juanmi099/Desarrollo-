 Rueda Nocturna
Página web de una comunidad que organiza rodadas en bicicleta de noche. Proyecto desarrollado con Tailwind CSS para el Entregable T1.

 Enlace publicado


 Descripción
Esta su html dividido en secciones

Sección	Contenido
Navbar	Logo y menú que lleva a cada sección
Inicio	Presentación con botones de llamada a la acción
Nosotros	Qué es Rueda Nocturna y cifras de la comunidad
Rodadas	Tarjetas con las próximas rutas
Seguridad	Recomendaciones para rodar de noche

Footer	Pie de página
Uso de Tailwind CSS
Todos los estilos están hechos con clases utilitarias de Tailwind; no hay estilos en línea ni archivo CSS propio.
Colores: slate (fondo oscuro), indigo (cielo nocturno) y amber 
Espaciados: p-*, px-*, py-*, m-*, gap-*.
Componentes: navbar, botones, tarjetas, etiquetas de nivel y formulario.
